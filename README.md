# LitSIMM-16MB_30
16MB FPM 30pin SIMM enhanced with 8 LEDs

There is enough clearance under SOJ chips for the 100nF 0603 caps to fit underneath.

Not suitable for hand soldering - reflow process necessary

They work with Sound Blaster AWE, compatible PC motherboards, old Apple, MIDI keyboards, samplers, etc. Just make sure your system supports the capacity.
